# 🛒 New English E-Commerce Platform

A modern full-stack e-commerce platform inspired by Old English Bakery & Superstores. Built as a digital replica of the physical store, New English allows customers to browse products and place orders while providing administrators with a dedicated dashboard to manage inventory and monitor customer orders.

Unlike traditional portfolio projects, New English features authentication, database integration, product management, and order tracking through a centralized admin dashboard.

## 📸 Overview

New English was developed as a digital representation of Old English Bakery & Superstores, providing an online storefront where customers can browse products and place orders.

The platform includes a dedicated administrative dashboard where authorized users can manage products, monitor orders, and maintain store inventory directly from the application.

## 🔄 Product Management Workflow

1. Administrator logs into the dashboard.
2. Products are created and stored in Supabase.
3. Existing products can be updated or removed.
4. Changes are reflected instantly on the storefront.
5. Customers browse the latest product listings.

---

## 📦 Order Workflow

1. Customer browses available products.
2. Customer places an order.
3. Order details are stored in Supabase.
4. Administrators can view orders in the dashboard.
5. Orders can be processed and managed centrally.

## ⚙️ Local Development

### Clone the Repository

```bash
git clone https://github.com/Sylvester009/new-english.git
cd new-english
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

### Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
